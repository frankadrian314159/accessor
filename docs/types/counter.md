# COUNTER (AutoNumber)

`COUNTER` is not a separate storage type: it is an [`INTEGER`](integers.md) column that numbers itself, the Access *AutoNumber*. Aliases: `AUTOINCREMENT`, `AUTONUMBER`, `SERIAL`. The standard spellings `GENERATED ALWAYS AS IDENTITY` and `GENERATED BY DEFAULT AS IDENTITY`, and the keywords `IDENTITY` and `AUTOINCREMENT` after a type, make an `INTEGER` column an AutoNumber in the same way.

```sql
CREATE TABLE Customer (
    ID    COUNTER PRIMARY KEY,
    Name  TEXT NOT NULL
);
-- the same:
--   ID INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY
--   ID INTEGER IDENTITY PRIMARY KEY

INSERT INTO Customer (Name) VALUES ('Ada'), ('Grace');     -- IDs 1 and 2
```

## How the numbers are given

* When an insert does not supply a value for the column, it gets the next number. Numbers start at 1 and go up by 1.
* **Numbers are never reused.** Deleting a record, or rolling back an insert, leaves a gap. After deleting the record with ID 11, the next record gets 12, not 11.
* A value you supply is kept, and the counter moves past it: after `INSERT ... (ID) VALUES (10)` the next automatic number is 11. A supplied value that is lower than the counter does not move it back. (`GENERATED ALWAYS` is accepted for the standard's syntax but still allows a supplied value.)
* The counter is stored with the table and survives restarts and compaction; it is part of the database file.

## Rules

* A table can have **one** AutoNumber column.
* The column must be `INTEGER` (a `COUNTER` is one); `ALTER TABLE ... ALTER COLUMN ... TYPE COUNTER` is refused: an existing column cannot be converted to an AutoNumber.
* The column is not required to be the primary key, but it nearly always is.
* In `INSERT` without a column list, the AutoNumber column takes part like any other: give `NULL` there to take the next number, or list the other columns by name.

## Gaps and the counter

Because numbers are never reused, an AutoNumber is an *identifier*, not a row count or a position. Do not rely on it being continuous. To number rows in a query, use [`ROW_NUMBER() OVER (ORDER BY ...)`](../functions/window.md#row_number).
